Free AI models: every day finds free, strong AI models (text, image, video, voice, speech recognition) on OpenRouter, NVIDIA and other sources, keeps a list of the good ones and writes the owner cards on how to use each in deck for free; proposes which free or cheap model should do each command of deck, tests it first and gives the owner a button to apply it.

Every day after the list is fresh, `compare` checks the models deck's work uses (gone at the source or broken in deck: one feed note), `plan` (a free agent) picks a better model for each piece of work from the candidates, and `test` tries each on a short sample (a tool call and JSON for an agent, a picture, speech) before the proposal shows as ready on the screen Proposals. `compare` reads which models do the work of each project itself (reads models of every project); a project it does not know yet is named to it once in `projects`. «Применить» calls deck.assignment_set and the proposal waits for the owner's one-button yes («ждёт вашего да»); «Добавить в deck» calls deck.model_set the same way.

The owner wants a short list of free models that are actually strong, not every free endpoint. Each good model gets a card with step-by-step instructions to connect it to deck: which key to get and where, which connection in Settings → Models → Connections holds it, how the model is declared in Settings → Models (or proposed by the master for the owner's yes), and, for voice, speech recognition, images, video and music, which role (@tts, @stt, @image, @video, @music) to assign it to so modules call it through deck.

Language of everything the owner reads (cards, how-to, strengths, limits): Russian.
